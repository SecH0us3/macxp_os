The Windows XP Experience for macOS

A standalone, pixel-accurate, and high-performance recreation of Microsoft Windows XP (Luna Blue) built natively in Swift & SwiftUI for macOS 13.0+ (Ventura, Sonoma, Sequoia).

✨ Authentic Nostalgic Features

3D Pinball: Space Cadet

SpriteKit physics engine with dual flippers, spring plunger, 3 reactive bumpers with light flares, rollover multipliers, and 7-segment LED scoreboard.

Solitaire (Косынка)

Authentic Klondike Solitaire with Draw 1/3 modes, Standard & Vegas scoring, customizable card backs (Castle, Beach, Robot), and the legendary bouncing victory cascade!

Windows XP Boot Screen

Authentic pitch-black startup screen with the iconic glowing 3 blue running cubes progress bar, smooth fade transition, and startup chime.

Macromedia Flash Player 8

Includes the legendary Flash Player with authentic context menu and built-in classics: Copter 2004 (Helicopter game) and Space Alien Blast!

My Computer & Explorer

Original XP system icons (CRT monitor, Local Disk C:, User Documents, Recycle Bin) with 5 view modes (Tiles, Icons, Details), address bar, and sidebars.

Internet Explorer 6

Classic blue e with gold halo, back/forward buttons, URL address bar with green Go button, and live WebKit browser rendering.

Windows Media Player & Sounds

Authentic sound engine with sample tracks (Like Humans Do, Windows XP Tour), animated spectrum visualizers, and classic XP audio effects.

3D Pipes & Starfield Screensavers

Classic 3D OpenGL-style Pipes and retro Starfield warp speed simulation with preview monitor in Display Properties.

💻 Complete Classic Applications Suite

Application Description
3D Pinball Space Cadet
SpriteKit table physics, dual flipper controls (Z / /), plunger launch, and space mission ranking.
Solitaire
Classic Klondike cards, Draw 1/3 modes, Standard & Vegas scoring, and bouncing victory cascade.
Windows Explorer
Virtual C:\ drive, breadcrumbs, parent directory traversal, and full macOS filesystem management.
Macromedia Flash Player
Flash 8 interface with Copter 2004 and Space Alien Blast retro arcade games.
Notepad
Lightweight text editor with File/Edit menus, Word Wrap, and Line/Column status bar.
Calculator
Standard calculator with memory keys, square root, percent, and keyboard input.
Minesweeper
3 difficulties, animated smiley face reaction button, and 7-segment digital LED timer.
MS Paint
Pencil, Brush, Line, Rectangle, Ellipse, Eraser tools, 28-color palette, and undo history.
Command Prompt
Real terminal session running macOS zsh subprocess with DOS aliases (DIR, CLS, CD, VER, ECHO).
